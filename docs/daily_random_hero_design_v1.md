# EDT/GOC 일일 단일 비공개 발행 상세설계

## 요구사항과 실행 계약

- 매일 KST 10:00을 GitHub Actions 예약 기준으로 한다(UTC cron `0 1 * * *`). 실제 시작은 GitHub 예약 지연에 따라 늦어질 수 있다.
- EDT와 GOC 중 한 캐릭터만 선택한다. 하루의 회차·시장 데이터·빌런을 공유하는 단일 발행 경로로 처리한다.
- 선택은 KST 날짜를 seed로 하는 의사난수 `Random("hero-v1:YYYY-MM-DD").choice(("EDT", "GOC"))`다. 재시도에도 같은 캐릭터가 선택된다. 각 날짜의 선택은 50:50 방식이며 기간별 정확한 반반 배분이나 교대는 보장하지 않는다.
- GOC 선택일은 당일 시장 수집 → 기존 빌런 규칙 → GOC 대본을 사용한다. 기존 EDT 발행 사건에 의존하지 않는다.
- 일일 중복 방지 및 전체 회차 번호는 기존 `episodes`를 공통 사용한다. `story_state.track`에 선택 캐릭터를 기록한다. DB 스키마 변경은 없다.
- GOC 음성은 Kore, 전용 참조 및 이미지 슬롯, EDT 아웃트로 생략을 사용한다. 제목·설명에 선택 캐릭터를 표시한다.
- 업로드 메타데이터의 `privacy=private`를 강제하여 환경변수 값과 무관하게 이 일일 경로는 비공개다.

## 처리 순서와 장애

1. 환경 검증과 기존 일일 발행 검사, YouTube 인증 사전 확인.
2. 당일 캐릭터 선택 및 시장 수집/필수 지표 검증.
3. 동일 회차·빌런 규칙으로 선택 캐릭터의 대본 생성. GOC 자막 길이 검사를 유료 이미지/TTS 전에 수행한다.
4. 회차 선기록 → 이미지 → TTS → 미디어 검증 → 렌더 → 영상 검증 → 비공개 업로드 → 발행 상태 갱신.
5. 실패 시 기존 실패/중단 상태와 단계 로그를 기록한다. 다른 캐릭터로 자동 전환하지 않는다.

기존 Actions concurrency와 일일 발행 검사를 유지한다. YouTube 업로드 성공 후 DB 갱신 실패 시의 완전한 원자성은 기존 경로에도 없으며 별도 복구 설계가 필요하다.

## 파일럿과 운영 검증

- `--daily-video-pilot`: 일일 선택 캐릭터의 저비용 한 장면 미리보기.
- `--video-pilot` / `--goc-video-pilot`: EDT/GOC의 저비용 한 장면 미리보기.
- 모든 기본 파일럿은 대본 생성 호출 0회, `gemini-3.1-flash-lite-image` 1K 세로 이미지 1회, `gemini-3.8-flash-lite-tts` 짧은 음성 1회(재시도 없음)만 사용한다. GOC 음색 Kore는 유지한다. 실패 시 고가 모델로 전환하지 않는다.
- 운영은 기존 표준 이미지/TTS 모델로 4장·6개를 생성한다. 운영 품질 6비트 검증용 `--production-video-pilot`은 CLI에서 명시적으로 사용할 수 있으며 기본 Actions 선택지에는 넣지 않는다.
- 이미지 출력 단가 $0.0336/1K장, Lite TTS 출력 $0.0015/10초(2026년 말까지 할인 단가). 입력 토큰·세금·환율은 별도이며 실제 사용량이 최종 과금을 결정한다. 출처: https://ai.google.dev/gemini-api/docs/pricing (2026-09-30 확인).
- 저비용 미리보기는 캐릭터 분위기·음색·화면 동작을 확인한다. 전체 시장 대본, 장면 연결, 운영 품질 승인 근거는 아니다.
- 검증 항목: 동일 날짜 재선택 일치, 두 캐릭터 분기, GOC 당일 독립 생성, Kore 전달, GOC 업로드 제목·설명, private 강제, 일일 중복 검사, 파일럿 DB/업로드 미호출, cron과 healthcheck 시각.
- 실제 Gemini/YouTube 결과와 영상 품질은 운영 Action 결과로 확인한다. Action 실행은 마스터가 직접 수행한다.

## 개발 검증 결과 (2026-09-30)

- 전체 단위테스트 323건 통과. 일일 선택 재현성, GOC 독립 생성, 공통 일일 중복 게이트, 환경변수가 public이어도 private 메타데이터가 우선하는 업로드 요청을 검증했다.
- 이전 운영에서 생성된 이미지와 WAV를 재사용한 로컬 파일럿: 실제 FFmpeg 렌더링·BGM·음량 정규화·ffprobe 검증 통과. 1080×1920, 7.02초. 한글 자막 화면을 확인했다. 이 검증은 새 Lite 모델을 실제 호출한 결과가 아니다.
- 새 Lite 이미지/TTS 모델의 계정 가용성 및 실제 품질, 일일 GOC 비공개 업로드는 새 운영 Action 실행으로 검증해야 한다.
