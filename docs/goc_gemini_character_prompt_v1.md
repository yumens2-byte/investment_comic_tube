# GOC 캐릭터 레퍼런스 생성 프롬프트 v1

Gemini 이미지 생성에 기존 GOC 원본 `1000060004.png`를 함께 첨부한 뒤 아래 프롬프트를 입력한다. 원본이 없으면 카논 일치 여부를 판정할 수 없으므로 새 이미지의 디자인을 확정 캐릭터로 취급하지 않는다.

```text
[REFERENCE IMAGE: 첨부한 1000060004.png는 Guardian of Capital(GOC)의 유일한 캐릭터 외형 원본이다. 화면 구성 참고가 아니라 외형 카논이다.]

첨부한 GOC를 EDT UNIVERS와 같은 세계관의 단독 캐릭터 레퍼런스 시트로 다시 그려줘. GOC는 Guardian of Capital, 자본을 보호하고 위험을 통제하는 히어로다. EDT를 대체하거나 EDT의 호랑이 얼굴·체인소·의상을 가져오지 마라.

원본의 얼굴, 인간 귀, 체형, 의상 구조, 색상, 문양, 무기·장비, 장신구를 각각 원본과 일치시켜라. 원본에 없는 무기·로고·동물 귀·꼬리·추가 인물을 만들지 마라. 식별이 어려운 부분은 임의로 채우지 말고 시각적으로 단순화하라. 좌우 장비 위치를 뒤집지 마라.

한 장의 단독 전신 기준 컷. 정면에 가까운 3/4 시점, 머리부터 발끝까지 보이며 손과 장비가 프레임 안에 온전히 들어오게 한다. 차분하지만 단호한 방어 태세. 의상과 장비 윤곽이 배경과 분리되도록 어두운 금융 도시 배경을 사용한다. 가독성을 위해 과도한 이펙트와 가림을 피한다.

스타일: EDT UNIVERS의 2D 시네마틱 슈퍼히어로 코믹, 굵고 정확한 선, 셀 셰이딩, 높은 명암 대비, 완성된 배경. 세로 4:5 구성. 화면 가장자리까지 완성하며 회색 빈 띠를 만들지 마라.

절대 금지: 읽을 수 있는 글자·숫자·티커·로고·말풍선·텍스트 박스, 추가 캐릭터, 캐릭터 디자인 변경, 손가락·사지 중복, 장비 좌우 반전.

결과는 이미지 한 장만 출력해줘.
```

결과를 승인한 뒤 원본 해상도의 PNG를 `assets/reference/goc/`에 넣어야 GOC 파일럿이 실행된다. 현재 코드의 GOC 음성은 Gemini TTS `Kore`를 지정한다. 실제 한국어 발화의 여성 음색과 발음은 생성된 영상에서 청취 검증한다.
