# GOC 개발 착수 및 테스트 현황

2026-09-30 기준. GOC 파일럿은 운영 `main`에 배포되었으며 실제 렌더링 검증 전 단계.

## 이번 변경

- 수동 `goc-video-pilot` 실행 경로: 최신 EDT 발행 회차의 `market_snapshot`과 빌런을 읽어 GOC 시점 대본·이미지 4장·여성 음성 설정 TTS 6개·영상을 생성한다. 파일럿은 당일 또는 전날(KST) 발행 사건까지 허용하고 원본 `market_as_of`를 로그와 대본 입력에 명시한다. 이틀 이상 지난 사건과 미래 날짜는 거부한다.
- GOC 참조 이미지 전용 디렉터리. 참조가 없으면 이미지 API 호출 전에 중단한다. EDT 참조가 섞이지 않는다.
- GOC의 EDT 전용 아웃트로를 생략한다. EDT 영상 경로와 비공개 업로드 환경값은 유지한다.
- Gemini 캐릭터 생성 프롬프트: `docs/goc_gemini_character_prompt_v1.md`.

## 미구현·운영 게이트

- `assets/reference/goc/goc_hero.png`가 2026-09-30 운영 `main`에 추가되어 개발 브랜치에 병합되었다. 실제 Gemini 이미지 생성과 음성 결과의 품질 검증은 아직 수행하지 않았다.
- GOC 자동 비공개 업로드, 점심/퇴근 이중 예약, 트랙별 DB 회차·멱등성은 구현되지 않았다. 운영 스키마의 실제 제약과 기존 `episodes` 사용 방식 확인 후 구현한다.
- Gemini `Kore` 음색은 설정값으로 선택했으며 실제 한국어 결과를 청취하여 여성 음색·발음·속도 판정이 필요하다.
- EDT 원본의 `market_as_of`는 현재 코드에서 레코드 생성 시각이다. 지표별 관측 시각 계약은 별도 개발이 필요하므로 새 영상 공개 품질을 이 파일럿만으로 승인하지 않는다.
- GOC 대본에 제공 수치 외 숫자가 포함되지 않는지 자동 사실 검사는 아직 없다.
- 2026-09-30 오전 6:53, 6:58 KST의 운영 파일럿은 당일 EDT 발행 전 날짜 게이트에서 중단되었다. 이 문서의 전날 허용 수정은 재배포 후 파일럿 재실행으로 검증해야 한다.

## 재현

`python -m unittest discover -s tests -q` → 참조 이미지 로딩 테스트를 포함해 재실행한다. `goc-video-pilot`은 YouTube API 업로드와 DB 쓰기를 호출하지 않는다. 수동 실행 산출물의 캐릭터 외형·자막·음성·시세를 확인한다.
