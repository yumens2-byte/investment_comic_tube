# 쇼츠 품질 운영 베타 상세설계 v3

## 검토 범위와 근거

2026-09-29 파일럿 #58의 영상, 이미지 4장, TTS 6개, 실행 로그를 검토했다. 영상은 약 40초였고 첫 이미지 하단에 넓은 단색 영역이 있었다. 훅 TTS는 약 4.88초인데 고정 3초 구간에 최대 1.5배속을 적용하여 끝 음절이 잘릴 수 있었다. 본편에는 화면 자막이 없었다. 실제 관계자 회의가 아닌, 시청자(1), 편집·자막(2), 음성·TTS(2), 시장 데이터·금융 검토(2), 캐릭터·미술(2), 운영·QA(1)의 10개 관점 점검이다.

## 이번 구현

| --- | --- | --- |

## 운영 베타 절차와 종료 기준

1. 변경을 main에 배포하고 `video-pilot`을 수동 실행한다. 파일럿은 이미지·TTS·조립까지 운영과 동일하게 수행하되 YouTube 업로드를 하지 않는다.
2. 성공 여부만 보지 않고 아티팩트의 영상 전체를 청취하고, 첫 장면과 모든 장면의 중간·말미 프레임을 확인한다. 숫자와 출처는 실행 로그 및 관측일과 대조한다.
3. 통과 조건: 이미지 4장 정상, 한글 자막 전 구간 판독 가능, 훅과 본편의 문장 끝 무절단, 음성·화면 동기화, 60초 이내, 업로드 0건, 같은 날짜 운영 중복 발행 0건.
4. 실패하면 해당 로그·영상 시점을 기록하고 원인 수정, 단위테스트, 재배포, 파일럿 재실행을 반복한다. 파일럿 통과 전 신규 운영 발행을 성공으로 기록하지 않는다.

## 후속 설계 항목

- 시장 데이터마다 `observed_on`, 시세 시간대, 실제 제공원과 원본 식별자를 보존하고, 대본의 사실 문장을 확인 가능한 관측치에 연결한다. stale 기준은 시장 휴장일을 포함해 별도로 정한다.
- 캐릭터 정합성은 자동 이미지 검사만으로 보장할 수 없다. 기준 시트와 샷별 육안 승인 기록을 둔다.
- 비공개 YouTube 업로드와 공개 발행의 상태를 구분하고, 재시도 시 같은 episode와 영상의 중복 업로드를 방지한다.
- 시청 지속률, 첫 3초 이탈, 댓글의 이해도 신호를 회차별로 관찰하되 조회수만으로 품질을 판정하지 않는다.

## 제약

실제 이해관계자 인터뷰와 실제 시청자 반응 검증은 수행되지 않았다. 이번 설계의 10개 관점은 역할 기반 검토이며, 운영 파일럿 결과는 배포 후 새 실행의 아티팩트로 별도 확인해야 한다.
